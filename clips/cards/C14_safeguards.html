What could go wrong

Safeguards built in, not bolted on.

⏸

Paused by default

Every drafted ad is created paused. It only goes live when a person clicks Approve.

✓ tested: a smuggled "ACTIVE" status is ignored
🔒

Scoped tools

Read tools are separate from draft tools. No tool can change budgets, statuses or live ads.

✓ the weekly job runs read-only
📜

Audit log

Every tool call, report run and approval: who, what, when, and the result.

✓ visible live in the dashboard
🔑

Keys in env vars

API keys live in environment variables, never in code or in the repo.

✓ .env.example only
